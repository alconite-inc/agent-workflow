# Design provenance

Agent Workflow v1 is independently authored. It was informed by a design
review of Brad Traversy's MIT-licensed `ai-blueprint` repository at commit
`8bcd450da903795e5df0a651c92445e7084b3761`.

The review evaluated user-owned plans, generated context, bounded
specifications, implementation proof, findings gates, durable history, resume,
and adapter projection. This implementation independently defines its schemas,
prose, event model, worktree isolation, exact-digest approval, exact-revision
proof, independent review, release evidence, authorization boundaries,
validation, and distribution model.

Derivation mode is `original`. No substantial upstream source or prose is
distributed. If that changes, the distribution must switch to `adapted` and
include both the applicable full license notice and an exact source map.
